## What this repo is
The `529` repository houses the ORA Advisory automation platform and content pipeline. It provides an end-to-end framework for generating high-leverage consulting deliverables, executive presentation decks, and published thought leadership articles from research briefs. The platform leverages Claude LLM prompt chains (via `anthropic`), Gamma API integration for visual presentation generation, Marp CLI for Markdown slide previews, custom computer-vision quality assurance tools (using `Pillow` and `numpy`), and a Jekyll static site generator for publishing thought leadership to `zoheri.com`.

## What is actually built

### 1. Presentation Deck Generation Engine
* **Gamma API Integration (`gamma_deck.py`)**: Primary presentation deck generation engine (`GammaDeck`) communicating with the Gamma REST API (`https://public-api.gamma.app/v1.0`). Handles theme listing, asynchronous deck generation from Markdown prompts, status polling (`_wait_for_completion`), and PDF/PPTX artifact downloading. Per ADR-001, Gamma API serves as the primary deck production pipeline.
* **Marp Slide Pipeline (`automation/generate.py`)**: Implements a 3-step prompt chain utilizing Claude (`anthropic` API):
  1. `step1_framework`: Transforms client brief into structured analysis frameworks.
  2. `step2_findings`: Translates frameworks into core analytical findings.
  3. `step3_deck`: Compiles findings into Marp-compliant Markdown presentation decks formatted with custom CSS theme headers (`MARP_HEADER`).
* **Legacy PPTX Generator (`ora_deck.py`)**: Retired fallback generator using `python-pptx` kept for backward compatibility and offline layout export.

### 2. Computer Vision Slide QA Subsystem (`visual_qa/`)
* **Exporter (`visual_qa/exporter.py`)**: Converts input slide documents (PDF via `pdftoppm` / `poppler-utils` or PPTX via `libreoffice`) into high-resolution PNG image frames for inspection.
* **Inspector (`visual_qa/inspector.py`)**: `SlideInspector` module evaluating slide PNGs against visual standards defined in `visual_qa/standard.yaml`. Measures aspect ratio (16:9 widescreen target), pixel dimensions (1920x1080), slide orientation, text coverage threshold (max 60%), whitespace breathing room (min 25%), content zoning (header and footer alignment), and palette adherence (Terracotta `#C45C26`, Sage `#7C9070`, Cream `#FDF8F3`, Charcoal `#2D3436`).
* **QA Reporter (`visual_qa/inspector.py`)**: Compiles quantitative check results into slide-by-slide Markdown diagnostic QA reports (`generate_report`).

### 3. Content Factory Pipeline (`content_factory/`)
* **Pipeline Orchestrator (`content_factory/pipeline.py`)**: `ContentFactory` module managing batch and single-topic execution across 6 lifecycle stages:
  1. Source research corpus ingestion (`work_corpus.md` and `research/*.md`).
  2. Article draft generation via Anthropic API.
  3. Draft automated evaluation and `.eval.json` scoring.
  4. Iterative draft revision and polish.
  5. Gamma deck export and conversion.
  6. Visual QA inspection and selection for publication to `site/writing/`.

### 4. Static Thought Leadership Website (`site/`)
* **Jekyll Publishing Engine (`site/`)**: Static site source for `zoheri.com`. Configured via `_config.yml` and liquid layouts (`_layouts/default.html`, `_layouts/article.html`). Houses published articles in `site/writing/` covering enterprise cost reduction, remote work operations, higher-ed restructuring, and data reconciliation.

### 5. Consulting Project Workspaces (`projects/`, `deliverables/`)
* **Project Structure**: Standardized workspace structure (per ADR-004) containing client brief inputs (`00-brief.md`), domain research (`01-research.md` / `research/`), analysis frameworks (`02-analysis.md`), findings (`03-findings.md`), deck outlines (`04-deck-outline.md`), customized generation scripts (`generate_deck.py`), and output QA reports. Standard projects include `projects/higher-ed-admin-cost/` and `projects/r1-ai-strategy/`.

### 6. Templates, Prompts, and Reference Data (`templates/`, `research/`, `linkedin-data/`)
* **Prompt & Deck Templates (`templates/`)**: Contains reusable prompt chains (`prompts/call-prep.md`, `prompts/analysis-framework.md`, `prompts/findings-generator.md`, `prompts/deck-draft.md`) and baseline deck structures (`decks/consulting-template.md`).
* **Research & Knowledge Base (`research/`, `docs/adr/`)**: Domain benchmarks, legal entity analyses (`llc-decision-analysis.md`), and Architecture Decision Records (ADRs 001-006).
* **Network & Resume Data (`linkedin-data/`, `archive/`)**: Historical CSV exports of profiles, engagements, job application answers, and network interaction history used for expert network profile matching.

## Canonical entry points

### Visual Quality Assurance
* `python3 -m visual_qa inspect <pdf_or_pptx>` — Render PDF/PPTX slides to PNG and run visual QA check suite, writing a Markdown report.
* `python3 -m visual_qa check <png_file> [png_file2 ...]` — Inspect pre-rendered PNG slide images directly against visual standards.
* `python3 -m visual_qa deps` — Validate host system binary dependencies (`pdftoppm`, `libreoffice`).

### Deck Generation & Marp CLI
* `python3 gamma_deck.py` — Run primary Gamma API integration to generate presentation decks.
* `python3 automation/generate.py brief.txt [output_dir]` — Run 3-step Claude LLM prompt chain converting brief text into Marp Markdown slides.
* `python3 projects/higher-ed-admin-cost/generate_deck.py` — Execute project-specific deck build pipeline.
* `npm run deck` — Start local Marp HTML slide preview (`npx marp --html`).
* `npm run deck:pdf` — Render Marp Markdown slides to local PDF (`npx marp --pdf --allow-local-files`).
* `npm run deck:watch` — Live watch mode for Marp Markdown slide authoring (`npx marp --watch --html`).

### Content Factory Pipeline
* `python3 -m content_factory.pipeline generate <topic_id>` — Generate initial article draft from topic ID.
* `python3 -m content_factory.pipeline evaluate <article_path>` — Perform automated LLM quality evaluation on draft article.
* `python3 -m content_factory.pipeline gamma <article_path>` — Export article draft into Gamma presentation deck.
* `python3 -m content_factory.pipeline batch <start_id> <end_id>` — Execute batch generation and evaluation across a range of topic IDs.
* `python3 -m content_factory.pipeline full <topic_id>` — Execute complete draft-to-QA pipeline for specified topic.

### Web Site Development
* `cd site && bundle exec jekyll serve` — Run local Jekyll development server for site preview.
