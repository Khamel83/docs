## What this repo is
Penny is a local-first voice capture pipeline and middleware. It ingests audio recordings from Apple Watch/Voice Memos and authenticated HTTP webhooks, stages raw files locally, records canonical state in an additive SQLite database (`~/.penny/transcripts.db`), transcribes offline using a pinned `mlx-whisper` model (`mlx-community/whisper-large-v3-turbo` at revision `a4aaeec0636e6fef84abdcbe3544cb2bf7e9f6fb`), validates transcript quality against repetition and token diversity rules, and routes downstream effects to Slack, Maya v2, Apple Notes, Apple Reminders, and Hermes capability execution. iCloud Drive acts as a rebuildable mirror, while versioned homelab backup sets provide isolated disaster recovery.

## Machine & Host Ownership
Production runs on single host `macmini` under macOS `user-launchd` services (`penny`). Local operational storage resides under `~/.penny/` (`/Users/macmini/.penny/`). No multi-host deployment configuration exists in status probe output or repository configs.

## What is actually built
- **Canonical Storage & State Ledger (`transcript_log.py`, `core.py`)**: `transcript_log.py` owns the SQLite schema (`~/.penny/transcripts.db`). It enforces deduplication via a `content_hash` UNIQUE constraint and maintains outbox records with attempt counters (`SLACK_MAX_ATTEMPTS = 5`), idempotency keys, and delivery receipts for Slack, Maya v2, Reminders, and Google Tasks. Advances Voice Memos discovery cursor only following durable `voice_memo_ingest` upserts. `core.py` provides shared domain types and pipeline mechanics.
- **Ingestion & Watcher Service (`watcher.py`, `webhook/server.py`, `ingress_auth.py`, `tasks_poller.py`)**: `watcher.py` orchestrates Voice Memos directory polling, staging, offline MLX transcription execution, quality checks, database persistence, and outbox delivery polling. `webhook/server.py` implements an HTTP ingress server for audio uploads and remote triggers, authenticated via `ingress_auth.py` using `PENNY_WEBHOOK_SECRET`. `tasks_poller.py` handles background synchronization with Google Tasks.
- **Offline MLX Transcription & Quality Verification (`config.py`, `transcript_quality.py`, `scripts/pin_whisper_model.py`)**: `config.py` pins the transcription identity to `mlx-community/whisper-large-v3-turbo` revision `a4aaeec0636e6fef84abdcbe3544cb2bf7e9f6fb` requiring `HF_HUB_OFFLINE=1`. `transcript_quality.py` runs deterministic transcript verification, checking control tokens (`CONTROL_TOKEN_RE`), token repetition limits (`MAX_CONSECUTIVE_TOKEN_REPETITION = 3`), natural emphasis exceptions (`NATURAL_EMPHASIS_TRIPLICATE_TOKENS = frozenset({"no"})`), and suffix diversity (`LOW_DIVERSITY_SUFFIX_MAX_UNIQUE_TOKENS = 2` over `SUFFIX_TOKEN_WINDOW = 20`). `pin_whisper_model.py` fetches and verifies weights against commit markers (`.penny-committed`).
- **LLM Classification & Maya Reasoning (`classifier.py`, `maya_delivery.py`)**: `classifier.py` provides transitional transcript classification via OpenRouter (`https://openrouter.ai/api/v1/chat/completions`), categorizing notes into `groceries`, `errands`, `home`, `health`, `work`, `kids`, and `inbox`. `maya_delivery.py` handles durable outbox messaging to Maya v2 for interpretation, approval state management, and action envelope generation.
- **Downstream Delivery & Projections (`slack_delivery.py`, `apple_effects.py`, `reminders.py`)**: `slack_delivery.py` implements durable Slack posting (channel `C0BKS0QT7FU`) with fallback from `requests` to `urllib.request` and lease-margin locking (`SLACK_CLAIM_LEASE_MARGIN_SECONDS = 5`). `apple_effects.py` and `reminders.py` manage client projections to Apple Notes and Apple Reminders.
- **Archiving & Backup Subsystems (`archive.py`, `backup.py`, `scripts/backup_penny.py`, `scripts/verify_penny_backup.py`)**: `archive.py` writes immutable local audio objects and publishes audio, `.md` transcripts, and `.json` manifests to the iCloud Drive `Penny Archive` mirror. `backup.py` manages versioned local backups (`BACKUP_SCHEMA_VERSION = 1`, `BACKUP_RETENTION_DAYS = 90`) using atomic sibling directory writes and scratch-only verification of SQLite snapshots, content objects, and catalogs.
- **Readiness Probe & Trust Verification (`doctor.py`, `scripts/penny_doctor.py`, `scripts/trust_check.py`)**: `doctor.py` and `penny_doctor.py` run metadata-only readiness probes, returning exit code 0 (ready), 1 (degraded), or 2 (unready). Probes evaluate `/health` and `/ready` endpoints bound to Voice Memos evidence without exposing raw audio, transcripts, PII, or credentials. `trust_check.py` validates system boundaries.
- **System Service Templates & Maintenance Scripts (`launchd/`, `scripts/`, `homelab.yaml`)**: Launchd plist templates (`com.penny.watcher.plist.template`, `com.penny.webhook.plist.template`, `com.penny.tasks.plist.template`, `com.penny.export.plist.template`) define macOS service units. Maintenance utilities include `export_transcripts.py`, `re_evaluate_quality_review.py`, `replay_maya_delivery.py`, and `google_auth.py`. `homelab.yaml` declares service lifecycle (`phase-a-candidate`), monitoring, secrets, and health checks.
- **Test Suite (`tests/`)**: Covers Apple effects (`test_apple_effects.py`, `test_apple_effects_integration.py`), archiving (`test_archive.py`), backups (`test_backup.py`), configuration (`test_config.py`), core/classifier (`test_core_and_classifier.py`), readiness probes (`test_doctor.py`), and model pinning (`test_model_pin.py`).

## Canonical entry points
- **Readiness Probe**: `venv/bin/python scripts/penny_doctor.py` (Metadata-only readiness check; exits 0=ready, 1=degraded, 2=unready).
- **Core Watcher Service**: `python3 watcher.py` (Discovers audio, drives transcription, quality gates, and delivery outbox polling).
- **Webhook Ingress Server**: `python3 webhook/server.py` (HTTP service accepting incoming uploads and webhooks).
- **Google Tasks Synchronization**: `python3 tasks_poller.py` (Background polling daemon for Google Tasks).
- **Model Provisioning & Pinning**: `python3 scripts/pin_whisper_model.py` (Downloads and verifies local MLX model weights).
- **Backup & Verification**: `python3 scripts/backup_penny.py` (Creates versioned snapshot set) and `python3 scripts/verify_penny_backup.py` (Scratch-only backup verification).
- **Maintenance & Recovery**: `python3 scripts/export_transcripts.py`, `python3 scripts/re_evaluate_quality_review.py`, `python3 scripts/replay_maya_delivery.py`, `python3 scripts/trust_check.py`.
- **Automated Test Suite**: `pytest tests/` (Executes core, archive, backup, doctor, config, and effect integration tests).
